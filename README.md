# EV:ON

지역과 차량 세부 모델로 조회하는 전기차 예상 구매보조금.

## 실행

Node.js 22.13 이상에서 `npm run dev`. `npm run build`로 Sites용 Cloudflare Worker를 생성합니다.

GitHub Pages 화면은 `npm run build:pages`로 `dist-pages/`에 생성합니다. GitHub 저장소의 Pages Source를 GitHub Actions로 설정하면 `main` 커밋마다 검증과 빌드 후 `https://garykwon.github.io/website3/`에 게시합니다. Pages는 정적 호스팅이므로 금액·제원·잔여 대수는 기존 서버에서 매번 재조회합니다. Pages에서 로그인 없이 조회하려면 API 서버도 공개 접근이 가능해야 합니다. 서버는 정확히 `https://garykwon.github.io`에서 온 교차 출처 읽기만 허용하며 인증 쿠키를 공유하지 않습니다. 프런트엔드는 기존 Sites와 같은 화면·자동 갱신·URL 복원 처리를 사용합니다.

## 화면

첫 화면은 그라디에이션 배경과 글래스 지역 검색창만 표시합니다. 지역 선택 후 제조사 → 차량 → 공식 세부 모델·휠·구동 방식을 고르면 국비·지방비와 합계가 즉시 바뀝니다. 도 검색은 시·군 선택으로 이어지며 구 검색은 담당 지원기관으로 연결합니다. 모바일에서는 예상 합계를 하단에 고정합니다.

## 공식 데이터

`/api/regions`, `/api/vehicles?region=1100&type=passenger|cargo`, `/api/subsidies?type=passenger|cargo`.

무공해차 통합누리집의 지역별 모델 금액 조회 `getLocalCarModelPrice.ajax`와 지급대상 제원 조회 `selectTargetVehicle.ajax`를 서버에서 읽습니다. 인증받은 공식 API라는 의미는 아닙니다. 모델 금액 표시는 `SUM_GAMT` 우선, `LAMT`, `TOTAL_AMT`를 만원 단위로 사용합니다. 차량가격 계수를 다시 적용하지 않습니다.

차량 옵션은 공식 모델 ID에 연결된 정확한 사양만 조회합니다. 모델명 묶음과 휠·구동 방식 추출은 화면 탐색용이며 금액을 추정하는 데 사용하지 않습니다. 제원은 제조사·세부 모델명이 정확히 하나만 일치할 때만 연결합니다. 누락·중복 제원과 알 수 없는 금액은 추정하지 않습니다. 공식 단종 표기 모델도 원문과 동일하게 포함하며 단종 상태를 표시합니다.

전환지원금을 선택하면 게시된 `EXCHANGE_3YEAR_GAMT3`와 `EXCHANGE_3YEAR_LAMT3`만 기본 소계에 한 번 더합니다. 3년 이상 경과한 내연기관차 본인 보유·처분 등 공고 요건을 충족해야 합니다. 청년·다자녀·차상위 등 개인 추가 지원 및 공식 모델명에 없는 선택품목은 계산하지 않습니다. 지급 확정액을 보증하지 않으며 접수 마감도 별도로 표시합니다.

제원 출처: https://ev.or.kr/nportal/buySupprt/initSubsidyTargetVehicleAction.do

## 자동 검증·갱신

지역 선택·차종 전환·5분 간격·재활성화 시 조회합니다. 새로고침과 순차 API 요청은 금액·제원·현황 원문을 매번 다시 조회합니다. 성공값을 5분 동안 재사용하지 않으며, 동시에 도착한 같은 요청만 합칩니다. 원문 요청은 캐시를 우회하고 12초로 제한하며 실패 후 다음 요청도 즉시 재시도합니다. 지역·연도·모델, 금액 단위, 합계와 중복, 공식 지급대상 국비와의 불일치, 제원 원문 시각, 이전 조회 대비 국비·지방비·총액 급변을 검사합니다. 합계가 불일치하면 계산 총액을 표시하지 않습니다.

공식 사이트 접속 실패 시 마지막 성공 데이터와 확인 시각을 표시하고 최신 검증으로 표시하지 않습니다. 초기 수집본은 실제 서울·수원·부산·제주 자료이며 다른 지역 금액으로 대체하지 않습니다. 지원현황과 차량금액 모두 한국시간의 현재 연도를 조회하고 다른 연도의 초기값을 재사용하지 않습니다. Cloudflare Cache API와 메모리에는 실패에 대비한 마지막 성공값만 보관합니다. 메모리는 차량 최대 8개/12MiB, 현황 최대 2개/6MiB, 비활성 30분 만료로 제한합니다. 금액·제원 요청은 동시 2개·대기 16개이며 대기 취소·요청 타이머와 스트림을 정리합니다. 원격 JavaScript를 실행하지 않습니다.

## 검증

`npm test`

`npm run typecheck`

`npm run build`

`node --import tsx scripts/audit-official.mts`는 공식 원문을 실제로 전수 조회하는 별도 감사입니다. 일반 회귀 테스트는 실제 네트워크를 사용하지 않습니다.

브라우저에서 지역·도 선택, 실제 사양별 금액 변동, 전환지원금 합산과 모바일 화면을 점검했습니다.

선택한 지역·차종·공식 모델 ID는 URL에 저장하며 새로고침 시 최신 데이터를 받아 복원합니다. 개인 추가 지원 선택은 URL에 저장하지 않습니다. 행정안전부의 현재 16개 광역·229개 하위 지역명, 기존 명칭, 공식 보조금 지원기관 코드도 검사합니다. 행정구역 통합 명칭은 실제 보조금 운영기관 코드로 연결합니다. 검증 범위와 별도 의존성 감사 결과는 [검증 기록](docs/verification.md)을 참고하세요.

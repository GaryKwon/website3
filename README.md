# EV:ON

지역과 차량 세부 모델로 조회하는 전기차 예상 구매보조금.

## 실행

Node.js 22.13 이상에서 `npm run dev`. `npm run build`로 Sites용 Cloudflare Worker를 생성합니다.

GitHub Pages 화면은 `npm run build:pages`로 `dist-pages/`에 생성합니다. GitHub 저장소의 Pages Source를 GitHub Actions로 설정하면 `main` 커밋마다 검증과 빌드 후 `https://garykwon.github.io/website3/`에 게시합니다. Pages는 정적 호스팅이므로 금액·제원·잔여 대수는 기존 서버에서 매번 재조회합니다. Pages에서 로그인 없이 조회하려면 API 서버도 공개 접근이 가능해야 합니다. 서버는 정확히 `https://garykwon.github.io`에서 온 교차 출처 읽기만 허용하며 인증 쿠키를 공유하지 않습니다. 프런트엔드는 기존 Sites와 같은 화면·자동 갱신·URL 복원 처리를 사용합니다.

## 화면

첫 화면은 그라디에이션 배경과 글래스 지역 검색창만 표시합니다. 지역 선택 후 제조사 → 차량 → 공식 세부 모델·휠·구동 방식을 고르면 국비·지방비와 합계가 즉시 바뀝니다. 도 검색은 시·군 선택으로 이어지며 구 검색은 담당 지원기관으로 연결합니다. 모바일에서는 예상 합계를 하단에 고정합니다.

## 공식 데이터

`/api/regions`, `/api/vehicles?region=1100&type=passenger|cargo`, `/api/subsidies?type=passenger|cargo`.

무공해차 통합누리집의 지역별 모델 금액 조회 `getLocalCarModelPrice.ajax`와 지급대상 제원 조회 `selectTargetVehicle.ajax`를 서버에서 읽습니다. 인증받은 공식 API라는 의미는 아닙니다. 모델 금액 표시는 `SUM_GAMT` 우선, `LAMT`, `TOTAL_AMT`를 만원 단위로 사용합니다. 차량가격 계수를 다시 적용하지 않습니다.

차량 옵션은 공식 모델 ID에 연결된 정확한 사양만 조회합니다. 모델명 묶음과 휠·구동 방식 추출은 화면 탐색용이며 금액을 추정하는 데 사용하지 않습니다. 제원은 제조사·세부 모델명이 정확히 하나만 일치할 때만 연결합니다. 누락·중복 제원과 알 수 없는 금액은 추정하지 않습니다. 공식 단종 표기 모델도 원문과 동일하게 포함하며 단종 상태를 표시합니다.

전환지원금을 선택하면 게시된 `EXCHANGE_3YEAR_GAMT3`와 `EXCHANGE_3YEAR_LAMT3`만 기본 소계에 한 번 더합니다. 3년 이상 경과한 내연기관차 본인 보유·처분 등 공고 요건을 충족해야 합니다. 개인 조건은 메모리에만 보관하며, 생애 첫 자동차와 기존 차량 전환은 동시에 선택하지 않습니다. 공식 모델명에 없는 선택품목은 계산하지 않습니다. 지급 확정액을 보증하지 않으며 접수 마감도 별도로 표시합니다.

제원 출처: https://ev.or.kr/nportal/buySupprt/initSubsidyTargetVehicleAction.do

## 개인별 추가 지원

국가 지침에서 8개 계산 규칙을 읽습니다. 현재 확인한 기준은 승용 다자녀 100·200·300만원, 청년 생애 첫 자동차 20%, 차상위 이하 승용 20%, 화물 소상공인 30%·차상위 이하 30%·농업인 10%·택배 10%, 비초소형 전기택시 250만원입니다. 비율은 기본 국비 기준이며 각 차급·자격·증빙 요건을 적용합니다. 화물 차상위 이하와 소상공인은 같은 조항이므로 둘 다 선택해도 30%를 한 번만 적용합니다. 화물 소상공인과 전환지원금을 함께 선택하면 지역 공고의 중복 조건 확인 전까지 추가액과 최종 합계를 미확정으로 표시합니다.

노후 전기차 폐차 20만원(2026-12-31까지), 리스·렌탈 사업 목적 구매 최대 180만원, 초소형 지역거점 사업 50만원은 별도 확인 항목으로 안내하며 합계에 넣지 않습니다. BMS 업데이트 불가·사업 목적 구매·지역 사업 참여 등 별도 요건이 있습니다. 종료일이 지난 안내는 숨깁니다.

화면은 위 설명을 상수로 사용하지 않고 조회 당시 공식 HWPX 본문에서 금액·자격·종료일을 읽습니다. 국비 기준 비율은 기본 국비에 각각 적용하며 복리로 계산하지 않습니다. 개인 추가액에 지방비 비율을 다시 곱해 더하지 않으며, 확인되지 않은 국비·지방비 분담액도 만들지 않습니다.

차량 조회마다 공식 지침 게시판·첨부 목록·원문을 새로 확인합니다. 새 금액·나이 기준은 지원되는 조항 형식이면 재계산하며, 차종·자격·중복·분담 규칙이나 문서 형식이 달라져 해석할 수 없으면 추가 합계를 표시하지 않습니다. 연도가 다르거나 30분 넘게 지난 규칙도 합산하지 않습니다. 같은 시점의 중복 요청만 합치며 성공 응답을 다음 순차 조회에 재사용하지 않습니다.

지자체 별도 지원과 제조사 할인은 국가 기준 예상 합계에 넣지 않습니다. 전국 160개 지원기관 × 승용·화물의 320개 공고 인덱스를 대조했고, 조회 시 비고·첨부 연결을 갱신합니다. 이 연결 검증은 모든 지역의 추가금액·중복 자격을 의미 검증했다는 뜻이 아닙니다. [추가 지원 검증 범위](docs/additional-benefits.md)를 참고하세요.

## 자동 검증·갱신

지역 선택·차종 전환·5분 간격·재활성화 시 조회합니다. 새로고침과 순차 API 요청은 금액·제원·현황 원문을 매번 다시 조회합니다. 성공값을 5분 동안 재사용하지 않으며, 동시에 도착한 같은 요청만 합칩니다. 원문 요청은 캐시를 우회하고 12초로 제한하며 실패 후 다음 요청도 즉시 재시도합니다. 지역·연도·모델, 금액 단위, 합계와 중복, 공식 지급대상 국비와의 불일치, 제원 원문 시각, 이전 조회 대비 국비·지방비·총액 급변을 검사합니다. 합계가 불일치하면 계산 총액을 표시하지 않습니다.

기본 금액·제원·지급현황 조회 실패 시 마지막 성공 데이터와 확인 시각을 표시하고 최신 검증으로 표시하지 않습니다. 초기 수집본은 실제 서울·수원·부산·제주 자료이며 다른 지역 금액으로 대체하지 않습니다. 지원현황과 차량금액 모두 한국시간의 현재 연도를 조회하고 다른 연도의 초기값을 재사용하지 않습니다. Cloudflare Cache API와 메모리에는 실패에 대비한 마지막 성공값만 보관합니다. 메모리는 차량 최대 8개/12MiB, 현황 최대 2개/6MiB, 비활성 30분 만료로 제한합니다. 금액·제원 요청은 동시 2개·대기 16개이며 대기 취소·요청 타이머와 스트림을 정리합니다. 원격 JavaScript를 실행하지 않습니다.

화면은 기본 금액·국가 추가 기준·지역 별도 지원의 확인 상태와 한국시간 조회 시각을 구분합니다. 기본 금액이 캐시이면 `이전 정보`, 국가 지침이 실패·만료하면 `확인 필요`로 표시하고 미확인 가산을 합산하지 않습니다. 지역의 `공고 목록 확인`은 목록 조회 시각이며 지급 조건 검증이나 지원 확정을 뜻하지 않습니다. 지역 조회 실패 시에는 최신 공고 확인이 필요하다고 표시합니다.

## 검증

`npm test`

`npm run typecheck`

`npm run build`

`node --import tsx scripts/audit-official.mts`는 공식 원문을 실제로 전수 조회하는 별도 감사입니다. 일반 회귀 테스트는 실제 네트워크를 사용하지 않습니다.

브라우저에서 지역·도 선택, 실제 사양별 금액 변동, 전환지원금 합산과 모바일 화면을 점검했습니다.

선택한 지역·차종·공식 모델 ID는 URL에 저장하며 새로고침 시 최신 데이터를 받아 복원합니다. 개인 추가 지원 선택은 URL에 저장하지 않습니다. 행정안전부의 현재 16개 광역·229개 하위 지역명, 기존 명칭, 공식 보조금 지원기관 코드도 검사합니다. 행정구역 통합 명칭은 실제 보조금 운영기관 코드로 연결합니다. 검증 범위와 별도 의존성 감사 결과는 [검증 기록](docs/verification.md)을 참고하세요.

# 추가 지원 계산과 검증 범위

## 국가 기준

최신 확정 전기자동차 보급사업 지침을 공식 게시판에서 찾고, 첨부 목록과 전체 HWPX 본문을 다시 조회한다. 현재 확인 문서는 2026.6.23 개정 지침이다.

- 공식 게시글: https://ev.or.kr/nportal/board/generalView.do?ARTC_ID=24839&boardType=guide
- 확인한 문서 SHA-256: `d25b78a12fc299611201506099b362267b4e1e8c9b1f1d554771ffbeaffa1f63`
- 실제 조회에서는 고정 해시를 최신 여부로 간주하지 않고 새 파일 전체를 해석한다.

| 조건 | 현재 읽힌 기준 | 차급·자격 제한 |
| --- | --- | --- |
| 다자녀 | 2명 100만원, 3명 200만원, 4명 이상 300만원 | 18세 이하 자녀, 일반 승용·경소형 승용 |
| 청년 첫 자동차 | 기본 국비의 20% | 19~34세 개인, 생애 첫 자동차, 초소형 승용 포함 |
| 소상공인 | 기본 국비의 30% | 소형·경형·초소형 화물, 확인서 등 증빙 |
| 택배 | 기본 국비의 10% | 소형·경형·초소형 화물, 법정 집화·분류·배송 운송사업용 |
| 택시 | 250만원 | 비초소형 승용, 면허와 법인 중소기업 요건 |

중·대형 화물의 소형 산식 적용 예외는 구매자 가산 적용까지 명확히 정하지 않으므로 자동 가산하지 않는다. 기본 국비가 0이거나 기본 합계가 검증되지 않은 차량에도 정액 가산을 만들지 않는다.

비율은 추가 지원 이전의 기본 국비에 각각 적용한다. 예를 들어 화물 국비 1,000만원이면 소상공인 300만원과 택배 100만원을 더하며, 두 비율을 복리로 계산하지 않는다. 다자녀 정액은 비율 계산 뒤 더한다. 청년 생애 최초와 기존 내연기관차 3년 보유가 필요한 전환지원금은 서로 배타적이다.

국가 지침은 구매자 가산을 국비·지방비 비율로 분담하도록 규정한다. 국비 500만원의 20%인 추가액 100만원에 지방비 비율을 다시 더하면 과다 계산이다. 화면은 기본·전환 국비/지방비와 개인별 추가 예상액을 별도 행으로 보여준다. 분담 반올림을 임의로 확정하지 않는다. 제조사 할인·지자체 독자 추가금은 합계에 포함하지 않는다.

## 모든 지원기관의 공고 연결 확인

2026-10-29 UTC에 승용·화물 각각 160개 지원기관, 총 320개 원문 인덱스를 대조했다. 첨부가 공시된 317개 기관·차종 조합에서 실제 파일을 수신했다. 318회 시도했으며 1회는 다른 공시 첨부로 재시도했다. 요청은 동시 2개, 파일 4MiB, 시간 12초로 제한했다.

- HWPX 210건은 전체 본문을 추출했다. 잘리는 미리보기 텍스트를 사용하지 않았다.
- PDF 73건, HWP 31건, ZIP 3건은 파일 연결·형식을 확인했다.
- 화물 첨부 미공시: 군산시(4513), 봉화군(4792), 창원시(4812).
- 파일 연결 확인 또는 키워드 발견을 지역별 지급액·중복 자격의 의미 검증으로 간주하지 않았다. 전체 지자체의 독자 추가금액이 모두 검증됐다는 의미가 아니다.

지급현황의 최신 비고와 공고 연결은 차량 조회 시 같이 갱신한다. 지역별 특례는 공고 확인 자료로 제공하며 자동 금액 합산에 사용하지 않는다. 최신 추경 공고가 이전 본공고의 조건을 유지할 수 있어, 새 파일에서 단어가 사라졌다는 이유로 지원이 없다고 판단하지 않는다. 부산 청년 EV드림처럼 시비와 제조사 할인이 섞인 사업은 전체 금액을 정부 보조금으로 넣으면 안 된다.

## 최신 규칙과 실패 처리

공식 목록의 현재 연도 확정 자동차 지침을 페이지 순회해 찾으며 초안·수소·충전·이륜차 문서를 제외한다. 요청마다 목록·첨부·본문을 확인하고 동일 시점의 중복 조회만 공유한다. 새 문서의 숫자 변경은 지원되는 문장 구조 안에서 다시 계산한다. 자격·차급·중복·분담·파일 형식 변경을 해석할 수 없거나 조회가 실패하면 규칙은 `unavailable`이며 이전 성공 규칙을 최신으로 재사용하지 않는다.

지침 조회는 전체 18초, 동시 1개·대기 4개로 제한한다. 압축 파일은 4MiB, ZIP 항목은 64개, 전체 해제 선언은 16MiB, 본문은 개별 3MiB·합계 8MiB로 제한한다. Workers 압축 해제기의 작업 버퍼 64KiB를 추가 허용하되 실제 출력 길이는 선언값과 정확히 일치해야 한다. CRC와 헤더, XML 구조를 검사하고 외부 엔터티를 해석하지 않는다. 원문 바이너리나 대용량 XML을 전역 캐시에 보관하지 않는다.

개인별 선택은 브라우저 메모리에만 존재한다. URL·로컬 저장소·조회 API 요청에는 저장하지 않으며, 지역·차종 변경이나 새로고침 때 초기화한다. 화면은 기본 원문 금액 대조와 개인별 자격·증빙을 구분한다.
